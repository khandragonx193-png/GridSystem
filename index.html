Nội dung chính

Chào mừng bạn đến với trang web thực hành Bootstrap Grid System.

Bootstrap là gì?

Bootstrap là một framework CSS giúp xây dựng giao diện website nhanh chóng, đẹp mắt và tương thích với nhiều kích thước màn hình.

Tìm hiểu Grid System

Bootstrap Grid System sử dụng hệ thống 12 cột. Chúng ta kết hợp các lớp row và col để chia bố cục thành nhiều khu vực.

  • container: Giới hạn chiều rộng nội dung.
  • row: Tạo một hàng chứa các cột.
  • col-lg-8: Chiếm 8/12 cột từ màn hình lớn.
  • col-lg-4: Chiếm 4/12 cột từ màn hình lớn.
  • col-12: Chiếm toàn bộ chiều rộng.

Thiết kế Responsive

Khi màn hình nhỏ hơn 992px, nội dung chính và sidebar sẽ xếp thành hai hàng. Trên desktop, hai khu vực nằm cạnh nhau.
